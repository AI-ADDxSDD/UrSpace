### Các Phương án đã Cân nhắc

| Lựa chọn thiết kế | Quyết định chốt và Lý do |
|---|---|
| Dùng thư viện Chart ngoài vs Tự vẽ SVG/CSS | Tự xây dựng SVG và Flexbox/Grid CSS thuần để kiểm soát hoàn toàn DOM, nhẹ, tải nhanh và không phụ thuộc thư viện bên ngoài. |
| Tính toán FSRS trên Client vs Gửi dữ liệu thô về Backend | Không tự ý tính FSRS trên Client; chỉ thu thập tương tác thực tế và gửi về Backend để bảo toàn độ chính xác của thuật toán lặp lại ngắt quãng. |
| Phóng to giao diện bằng CSS zoom vs CSS Responsive chuẩn | Tuyệt đối không dùng `zoom` hay `transform: scale()`; thiết lập hệ thống CSS Variables, font fluid và container `1360px` chuẩn mực. |

## Phản biện và Tác động (Cross-Review)

- **Rà soát Khả năng Tiếp cận (a11y):** Đảm bảo hỗ trợ phím tắt (`Space`, `1`–`4`, `Enter`, `Escape`), tiêu điểm bàn phím (`focus-visible`) và tương phản màu sắc đạt chuẩn WCAG AA.
- **Rà soát Trạng thái Rỗng và Lỗi:** Tất cả các màn hình đều có trạng thái Loading, Empty và Error thân thiện, không bao giờ để ứng dụng bị crash hoặc hiện màn hình trắng.
- **Rà soát Tương tác Mạng:** Mock API hỗ trợ kiểm tra độ trễ mạng và xử lý lỗi ngẫu nhiên, sẵn sàng chuyển đổi sang API endpoint chính thức khi Backend hoàn thành.
