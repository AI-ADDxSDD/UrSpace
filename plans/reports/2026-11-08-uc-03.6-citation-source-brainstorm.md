## 1. Problem-First Inversion (Phân tích Chiều sâu Vấn đề)

### 1.1. Nỗi đau thực tế: "Hội chứng Nghi ngờ Ảo giác AI (AI Hallucination Skepticism)"
- **Thực trạng**: Khi học viên ôn tập các thẻ bài học thuật chuyên sâu (Y khoa, Luật, Kỹ thuật, Lịch sử), nếu gặp một câu hỏi trắc nghiệm hoặc đáp án có vẻ trái ngược với hiểu biết thông thường, họ sẽ lập tức hoài nghi: *"Có chắc tài liệu gốc viết thế này không, hay Gemini tự sinh bậy?"*.
- **Hậu quả**: Nếu không có cơ chế đối chiếu ngay tại chỗ, học viên phải tạm dừng phiên học, mở file PDF 100 trang lên, nhấn `Ctrl+F` tìm kiếm mông lung $\to$ Gián đoạn dòng tập trung (Flow State) và làm giảm niềm tin vào nền tảng.
- **Giải pháp**:
  - Gắn một nút **"Đối chiếu nguồn" (View Source / Citation)** ngay trên mặt sau của mỗi Flashcard và trên Modal chi tiết của từng Khái niệm.
  - Khi bấm nút, một cửa sổ hoặc drawer mở ra ngay trong giao diện học tập, trỏ thẳng tới đúng số trang (`source_page`) và tự động bôi vàng đoạn văn bản gốc (`source_excerpt`) mà AI đã đọc.

### 1.2. Thách thức Hiệu năng: Tải File $25\text{MB}$ Xem 1 Trang
- File PDF bài giảng giáo trình có thể lên đến 25MB (100 trang).
- **Rủi ro chí mạng**: Nếu mỗi lần học viên bấm "Đối chiếu", frontend lại download toàn bộ 25MB từ server, thì:
  - Băng thông mạng cạn kiệt, độ trễ mở trang lên đến 3–5 giây.
  - Bộ nhớ RAM của máy chủ và client bị phình to.
- **Giải pháp chuẩn công nghiệp**:
  - Backend ASP.NET Core triển khai giao thức chuẩn **HTTP 206 Partial Content (Byte-Range Request)** thông qua `FileStreamResult(stream, "application/pdf") { EnableRangeProcessing = true }`.
  - Trình duyệt và thư viện PDF Viewer (PDF.js) chỉ cần tải vài chunk byte (khoảng $150\text{KB} - 400\text{KB}$) tương ứng với trang đang xem, mở tài liệu tức thì trong $< 300\text{ms}$.

## 2. Các Quyết Định Kỹ Thuật Đã Thống Nhất

| Hạng mục | Quyết định Kỹ thuật | Lý do & Giá trị mang lại |
| :--- | :--- | :--- |
| **Cơ chế Truyền tải File** | **HTTP 206 Partial Content (Byte-Range Streaming)** | Server chỉ đọc đúng byte range cần thiết từ ổ đĩa/MinIO, tiêu tốn RAM gần như $0$, hỗ trợ tua trang cực nhanh. |
| **Cơ chế Highlight** | **`source_page` + `source_excerpt` qua Text Layer** | Không lưu tọa độ pixel cứng (dễ lệch độ phân giải), mà dùng chuỗi trích dẫn gốc ($\ge 20$ từ theo luật `BR-12`) để PDF viewer tự highlight text layer. |
| **Bảo mật & Phân quyền** | **Xác thực Đa tầng (Owner & Shared Deck Learner)** | Chặn tuyệt đối truy cập công khai (no public enumeration). Chỉ chủ tài liệu hoặc học viên có quyền học bộ thẻ mới được stream file. |
| **Hỗ trợ Slide PPTX** | **Ánh xạ Slide Index (`source_page = slide_number`)** | Lưu số thứ tự slide của file PPTX, trả về đoạn trích dẫn và định danh slide để hiển thị chính xác. |
| **Bộ đệm & Caching** | **ETag & Cache-Control (Private, Max-Age)** | Giúp trình duyệt lưu đệm các trang đã đọc, lần sau mở lại không tốn thêm byte truyền tải mạng nào. |

## 3. Kiến Trúc Luồng Dữ Liệu (Data Flow)

```
[Học viên bấm nút "Đối chiếu nguồn" trên Flashcard / Concept]
                     │
                     ▼
  1. GET /api/v1/documents/{docId}/citation?cardId={cardId}
                     │
                     ▼ (Backend xác thực quyền & trả về metadata)
  Response: { source_page: 14, source_excerpt: "...", stream_url: "/api/v1/documents/{docId}/stream" }
                     │
                     ▼
  2. Frontend (PDF.js / React-PDF) gửi request Range: bytes=1048576-1572864
                     │
                     ▼
  3. Backend phản hồi HTTP 206 Partial Content (chỉ stream đúng chunk 512KB)
                     │
                     ▼
  4. PDF Viewer nhảy tới #page=14, tìm chuỗi source_excerpt trên Text Layer và Highlight màu vàng
```

## 4. Đặc Tả API Contracts (C# ASP.NET Core)

### 4.1. Lấy Thông Tin Trích Dẫn Nguồn (Citation Metadata)
* **Endpoint**: `GET /api/v1/documents/{documentId}/citation`
* **Query Parameters**:
  * `cardId`: `Guid` (Tùy chọn - nếu đối chiếu từ Flashcard)
  * `conceptId`: `Guid` (Tùy chọn - nếu đối chiếu từ Khái niệm)
* **Quy tắc Kiểm tra Quyền (Authorization)**:
  1. Người dùng hiện tại (`UserId`) là chủ sở hữu của `Document`.
  2. HOẶC Người dùng hiện tại đang tham gia học Bộ thẻ (`Deck`) chứa tài liệu này (nếu bộ thẻ được chia sẻ).
* **Response (HTTP 200 OK)**:
```json
{
  "success": true,
  "data": {
    "document_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
    "document_name": "Giao_Trinh_He_Dieu_Hanh_Chuong2.pdf",
    "file_type": "PDF",
    "source_page": 14,
    "source_excerpt": "Khối điều khiển tiến trình (PCB - Process Control Block) là cấu trúc dữ liệu cốt lõi lưu trữ toàn bộ trạng thái thực thi của tiến trình trong nhân hệ điều hành.",
    "stream_url": "/api/v1/documents/9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d/stream",
    "total_pages": 48
  }
}
```

### 4.2. Stream File Hỗ Trợ HTTP 206 Partial Content
* **Endpoint**: `GET /api/v1/documents/{documentId}/stream`
* **Headers Hỗ trợ**:
  * `Range: bytes=start-end` (VD: `Range: bytes=0-65535`)
  * `If-None-Match: "etag_hash"`
* **Response Headers (HTTP 206 Partial Content)**:
  * `HTTP/1.1 206 Partial Content`
  * `Accept-Ranges: bytes`
  * `Content-Range: bytes 0-65535/15728640`
  * `Content-Type: application/pdf`
  * `ETag: "sha256_hash"`
  * `Cache-Control: private, max-age=86400`

## 5. Cài Đặt Kỹ Thuật Chi Tiết (C# Code Reference)

```csharp
[ApiController]
[Route("api/v1/documents/{documentId:guid}")]
[Authorize]
public class DocumentCitationController : ControllerBase
{
    private readonly IDocumentCitationService _citationService;
    private readonly IFileStorageService _storageService;

    public DocumentCitationController(
        IDocumentCitationService citationService,
        IFileStorageService storageService)
    {
        _citationService = citationService;
        _storageService = storageService;
    }

    [HttpGet("citation")]
    public async Task<IActionResult> GetCitationMetadata(
        [FromRoute] Guid documentId,
        [FromQuery] Guid? cardId,
        [FromQuery] Guid? conceptId,
        CancellationToken ct)
    {
        var userId = GetCurrentUserId();
        var citation = await _citationService.GetCitationMetadataAsync(documentId, cardId, conceptId, userId, ct);
        return Ok(ApiResponse<CitationMetadataDto>.Ok(citation));
    }

    [HttpGet("stream")]
    public async Task<IActionResult> StreamDocument(
        [FromRoute] Guid documentId,
        CancellationToken ct)
    {
        var userId = GetCurrentUserId();
        var document = await _citationService.ValidateDocumentAccessAsync(documentId, userId, ct);

        var stream = await _storageService.GetFileStreamAsync(document.StoragePath, ct);
        var mimeType = document.FileType == DocumentFileType.Pdf ? "application/pdf" : "application/vnd.openxmlformats-officedocument.presentationml.presentation";

        // Bật cờ EnableRangeProcessing để ASP.NET Core tự động phân tích header Range và trả về HTTP 206
        return new FileStreamResult(stream, mimeType)
        {
            EnableRangeProcessing = true,
            EntityTag = new EntityTagHeaderValue($"\"{document.FileHashSha256}\""),
            LastModified = document.UpdatedAt
        };
    }
}
```

## 6. Kịch Bản Kiểm Thử & Tiêu Chí Chấp Nhận (Acceptance Criteria)

1. **Range Request Test (HTTP 206)**:
   - Gửi request `GET /stream` kèm header `Range: bytes=0-1023`.
   - Kết quả: Server trả về đúng status code `206 Partial Content`, header `Content-Range: bytes 0-1023/{total}` và body đúng 1024 bytes.
2. **Access Control Test**:
   - Dùng token của User B để stream tài liệu thuộc sở hữu của User A.
   - Kết quả: Hệ thống chặn ngay lập tức với HTTP 403 Forbidden.
3. **Excerpt Accuracy Test**:
   - Đoạn `source_excerpt` trả về đảm bảo $\ge 20$ từ theo luật `BR-12`.
   - Mở tài liệu ở trang `source_page`, tìm kiếm chuỗi `source_excerpt` $\to$ Khớp chính xác với nội dung văn bản trong tài liệu gốc.
4. **ETag Caching Test**:
   - Gửi request kèm `If-None-Match` bằng ETag cũ $\to$ Server trả về `304 Not Modified`, không tốn băng thông truyền tải.
